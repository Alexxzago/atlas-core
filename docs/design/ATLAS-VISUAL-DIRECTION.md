# Atlas Visual Direction

## Character

Atlas is precise, composed, and service-oriented. The visual language should feel like a trustworthy operations product: bright neutral surfaces, disciplined blue action emphasis, and restrained semantic status color.

## Hierarchy

- Page background separates the application frame from white working surfaces.
- Header and contextual selectors establish orientation before content.
- Section headings describe the operator's task; supporting text explains prerequisites or consequences.
- Cards group one bounded capability. Dividers organize dense configuration without creating nested panels.

## Typography And Layout

Use the existing system sans-serif stack for reliable multilingual rendering. Use a compact, readable type scale with comfortable line height; reserve all-caps for the Atlas wordmark only. Keep forms and reading surfaces constrained for scanning, while lists and operational content may use the available width.

Desktop uses a stable contextual frame and a centered work area. Mobile collapses secondary navigation, preserves 16px form text to avoid browser zoom, and keeps primary actions reachable. Layout uses logical CSS properties so directionality is not structurally blocked.

## Color And Status

Use semantic tokens, never hard-coded component colors. Action blue communicates interactive emphasis; success, warning, error, and processing colors communicate state alongside text and iconography when icons are introduced. Contrast must meet the accessibility standard in the companion document.

## Restraint

Avoid gradients, oversized marketing imagery, decorative illustration, and motion used only for novelty. The portal earns visual confidence through spacing, alignment, readable forms, and consistent feedback.
